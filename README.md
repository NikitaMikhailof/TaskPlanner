# Планировщик задач (Android)

Простое локальное приложение для планирования задач: без интернета, без аккаунтов, всё хранится на телефоне.

## Возможности

- Добавление, редактирование и удаление задач (название, описание, категория, срок, приоритет, отметка «выполнено»)
- Создание и удаление категорий (задачи удалённой категории переходят в «Без категории»)
- Фильтр списка по категории
- Уведомление, когда до срока выполнения задачи осталось 7 дней или меньше (проверка раз в сутки, работает при закрытом приложении)
- Стартовые данные загружены из файла «Плановые задачи.xlsx»: 14 задач и 7 категорий

## Как собрать APK (GitHub Actions, бесплатно)

1. Создайте репозиторий на github.com (например, `TaskPlanner`).
2. Загрузите туда всё содержимое этой папки — например:
   ```bash
   cd /home/nikita/project/TaskPlanner
   git init && git add -A && git commit -m "Task planner app"
   git remote add origin https://github.com/ВАШ_ЛОГИН/TaskPlanner.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** в репозитории — сборка запустится сама.
4. Когда сборка позеленеет (2–5 минут), откройте её, внизу в разделе **Artifacts** скачайте `TaskPlanner-debug-apk`.
5. Распакуйте архив и перекиньте `app-debug.apk` на телефон, откройте его и разрешите установку из неизвестных источников.

Пересобрать после изменений: push в репозиторий или кнопка **Run workflow** во вкладке Actions.

## Как пользоваться напоминаниями

- При первом запуске разрешите уведомления (запрос появится сам на Android 13+).
- Если уведомление не пришло: Настройки → Приложения → Планировщик задач → Уведомления → включить.
- Проверка выполняется раз в сутки; сразу после установки/открытия приложения она также выполняется в течение нескольких секунд.

## Требования

- Android 8.0+ (API 26)
- Не нужен ни интернет, ни Google Play
